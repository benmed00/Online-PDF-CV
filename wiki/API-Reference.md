# API Reference

Base URL (local): `http://localhost:3000`  
Base URL (production): `https://benyakoub-cv.firebaseapp.com`

**Canonical contract:** [`GET /api/openapi.yaml`](/api/openapi.yaml) (OpenAPI 3.1, generated from JSDoc)  
Human docs: `/docs` · Interactive Swagger UI: `/api/docs` (local Express only) · Maintainer guide: [docs/openapi.md](../docs/openapi.md)

## List resume versions

```http
GET /api/versions
```

### Response

```json
{
  "versions": ["default"],
  "count": 1,
  "baseUrl": "https://benyakoub-cv.firebaseapp.com/resume/"
}
```

Static equivalent (Firebase): `/api/versions.json` (generated by `npm run build`)

## Analyzer API (Node runtime)

These endpoints require a Node backend:

- **Local:** `npm start` (full Express app)
- **Production:** `api` Cloud Function when deployed with `firebase deploy --only functions,hosting`

Without the Cloud Function, the `/analyzer` page falls back to **client-side keyword scoring**.

See [functions/README.md](https://github.com/benmed00/Online-PDF-CV/blob/master/functions/README.md).

### Capabilities

```http
GET /api/analyzer/config
```

```json
{
  "openAi": true,
  "virusTotal": true,
  "maxUploadMb": 10,
  "supportedUploads": [".txt", ".docx", "..."]
}
```

### Analyze resume text

```http
POST /api/analyze
Content-Type: application/json
```

```json
{
  "text": "Resume plain text…",
  "targetRole": "engineering",
  "useAi": true
}
```

Returns keyword scores, best-practice checks, suggestions, and optional `aiInsights` when `OPENAI_API_KEY` is set.

### Upload and extract text

```http
POST /api/extract-resume
Content-Type: multipart/form-data
```

| Field  | Type | Description          |
| ------ | ---- | -------------------- |
| `file` | file | CV document (≤10 MB) |

Runs **VirusTotal** scan when `VIRUSTOTAL_API_KEY` is set, then extracts text from Word, Excel, PowerPoint, ODT, PDF, HTML, Markdown, images (OCR), etc.

| Status | Meaning                           |
| ------ | --------------------------------- |
| `403`  | File flagged malicious/suspicious |
| `422`  | Could not extract text            |

## Download default resume

```http
GET /resume
GET /resume/default
```

Returns `application/pdf`.

**Express:** falls back to `public/resume.pdf` when a version file is missing.  
**Firebase:** no fallback for unknown versions — returns 404 ([#27](https://github.com/benmed00/Online-PDF-CV/issues/27)).

---

## Download a specific version

```http
GET /resume/:version
```

### Parameters

| Name      | Type   | Rules                                                        |
| --------- | ------ | ------------------------------------------------------------ |
| `version` | string | Lowercase letters, numbers, hyphens only (`a-z`, `0-9`, `-`) |

### Examples

```bash
curl -O http://localhost:3000/resume/technical
curl -O http://localhost:3000/resume/executive
```

### Errors

| Status | Meaning              |
| ------ | -------------------- |
| `400`  | Invalid version slug |
| `404`  | PDF not found        |
