Resume API Documentation

This API allows you to access different versions of the resume in PDF format.

The resume is available in multiple formats tailored for different purposes.

Usage

Default Resume

GET /GET /resumeGET /resume/default

Returns the default resume in PDF format.

Specific Resume Versions

The following versions are available:

  • default - GET /resume/default

If a requested version doesn't exist, the default resume will be served.

API Endpoints

Resume Versions API

GET /api/versions

Returns a JSON object with information about all available resume versions.

Response Format

{
  "versions": ["default", "technical", "executive", "creative"],
  "count": 4,
  "baseUrl": "https://yourdomain.com/resume/"
}

You can use this endpoint to programmatically discover available resume versions.

Examples

cURL

curl -O https://yourdomain.com/resume/technical

JavaScript - Download Resume

fetch('https://yourdomain.com/resume/executive')
  .then(response => response.blob())
  .then(blob => {
    const url = window.URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = 'executive-resume.pdf';
    document.body.appendChild(a);
    a.click();
    a.remove();
  });

JavaScript - Get Available Versions

fetch('/api/versions')
  .then(response => response.json())
  .then(data => {
    console.log('Available versions:', data.versions);
    console.log('Total versions:', data.count);
    
    // Example: Create links for each version
    const container = document.getElementById('versions-container');
    data.versions.forEach(version => {
      const link = document.createElement('a');
      link.href = data.baseUrl + version;
      link.textContent = version;
      link.target = '_blank';
      container.appendChild(link);
    });
  });

Adding New Versions

To add a new resume version:

  1. Create a PDF file with your resume version
  2. Name it according to its purpose (e.g., technical.pdf, creative.pdf)
  3. Place it in the /public/resumes directory
  4. The new version will be automatically available at /resume/[filename-without-extension]
