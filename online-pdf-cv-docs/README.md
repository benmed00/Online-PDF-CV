# Online-PDF-CV Documentation

Bienvenue dans la documentation de l'application **Online-PDF-CV**. Ce projet est une application Node.js Express qui permet de servir un CV au format PDF en ligne. Cette documentation a pour but de vous guider à travers les différentes fonctionnalités de l'application, ainsi que les étapes nécessaires pour l'installer, la déployer et l'utiliser.

## Objectif du Projet

L'objectif principal de l'application est de fournir un moyen simple et accessible de partager un CV au format PDF via une URL. L'application est conçue pour être déployée sur Firebase Hosting, offrant ainsi une solution rapide et efficace pour rendre votre CV disponible en ligne.
