# Guide Rapide pour Online-PDF-CV

Bienvenue dans le guide rapide pour démarrer avec l'application Online-PDF-CV. Suivez ces étapes simples pour exécuter l'application après l'installation.

## Étape 1 : Installation des Dépendances

Assurez-vous d'avoir installé toutes les dépendances nécessaires. Vous pouvez le faire en exécutant la commande suivante dans le terminal :

```bash
npm install
```

## Étape 2 : Démarrer l'Application

Une fois les dépendances installées, vous pouvez démarrer l'application avec la commande suivante :

```bash
npm start
```

## Étape 3 : Accéder à l'Application

Après avoir démarré l'application, ouvrez votre navigateur et accédez à l'URL suivante :

```bash
http://localhost:3000
```

Vous devriez voir votre CV PDF accessible en ligne.

## Étape 4 : Déploiement sur Firebase

Pour déployer votre application sur Firebase, suivez les instructions dans la section [Déploiement](../deployment/firebase.md) de la documentation.

## Conclusion

Vous êtes maintenant prêt à utiliser l'application Online-PDF-CV. Pour plus d'informations, consultez la documentation complète.
