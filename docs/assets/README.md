# Documentation media

Playwright publishes screenshots and videos here during `npm run test:all`.

| Resource                 | Purpose                         |
| ------------------------ | ------------------------------- |
| [GALLERY.md](GALLERY.md) | Full screenshot & video index   |
| `screenshots/`           | PNG captures (desktop 1280×720) |
| `videos/`                | WebM recordings                 |

```bash
npm run test:all
```
